# ASSIGNMENT 1: BASIC CONTACT MANAGER CONSOLE APPLICATION

## Attributes of each contact:
- Name
- Phone Number
- Email Address
- Notes

## Features Implemented:
- VIEW Contacts
- ADD New Contacts
- EDIT Contacts
- DELETE Contacts
- SEARCH for a Contact

## Methods: 
- SearchIndex: To search for the index of particular elements in Contacts
- DeleteBy: To delete a contact by user provided data
- IsEmpty: To check whether the contacts list is empty
- ViewSorted: To view sorted contacts list as per user's sort by preference
- Main: Holds all basic functionalities of Contact Manager Application

## How to view & use contact app:
- Run the .cs file in Assignment 1
- Give Inputs as per the prompt:
- ENTER 0 to VIEW ALL CONTACT, 1 TO ADD NEW CONTACT, 2 TO EDIT EXSISTING CONTACT, 3 TO DELETE ANY CONTACT, 4 TO SEARCH ANY CONTACT, 5 TO VIEW SORTED LIST, 6 TO EXIT
