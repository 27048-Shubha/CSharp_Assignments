# Contact Manager - Console Application

## Purpose of this Application:
- Provides Basic Contact Management Operations Like Add, View, Update, Delete, Search, Sort

## How To - Navigation:

- Run the project and enter input as per prompt:
- ENTER 0 to VIEW ALL CONTACT
- 1 TO ADD NEW CONTACT
- 2 TO EDIT EXSISTING CONTACT
- 3 TO DELETE ANY CONTACT
- 4 TO SEARCH ANY CONTACT
- 5 TO VIEW SORTED LIST
- 6 TO EXIT

1. Add New Contact: 
- Provide Name, Number, Email, Notes
- Make sure the number you enter is exactly 10 digits
- Email & Notes are optional

2. Edit Existing Contact:
- Enter 1,2,3,4 to edit Name, Number, Email, Notes respectively 
- Once you enter new value, the old value will be replaced

3. Delete Existing Contact:
- Enter Phone number to be deleted
- If it exists, the number you entered will get deleted

4. Search Contacts:
- Enter Name of the contact 
- If it exists, the details of the contact will be displayed

5. View Sorted List
- Displays Contact List sorted by Name

6. Exit
- To quit Console Contact Manager
