# Error Handling App

A C# console application that demonstrates different exception handling techniques and debugging practices. The project showcases how to detect, handle, propagate, and analyze runtime errors to build more reliable applications.

## Tasks Overview

### Task 1: Division & Cleanup

- Demonstrates the use of `try`, `catch`, and `finally` blocks.
- Performs a division operation that can result in a `DivideByZeroException`.
- Displays a meaningful error message when an exception occurs.
- Ensures cleanup logic executes through the `finally` block regardless of the outcome.

### Task 2: Exception Wrapping

- Demonstrates catching and rethrowing exceptions.
- Handles `IndexOutOfRangeException` during array access operations.
- Throws a new exception with a custom message.
- Preserves the original exception using `InnerException` for easier diagnosis.

### Task 3: Custom Errors

- Demonstrates creating and using custom exception classes.
- Introduces `InvalidUserInputException` for invalid user inputs.
- Separates application-specific validation errors from built-in system exceptions.
- Provides clearer and more meaningful error messages.

### Task 4: Global Exception Handling

- Demonstrates application-level exception monitoring.
- Uses `AppDomain.CurrentDomain.UnhandledException` to capture unhandled exceptions.
- Displays a custom message when a fatal exception occurs.
- Shows how unhandled exceptions can be logged before the application terminates.

### Task 5: Stack Trace Analysis

- Demonstrates exception stack trace inspection.
- Captures and displays the stack trace generated by an exception.
- Identifies the method call sequence that led to the failure.
- Explains how to interpret stack trace information such as exception type, source method, and line numbers.
