# Calculator application with math operations utility

## Description

This project contains a simple `MathUtils` class that provides basic arithmetic operations on two integer values.

The class supports:

- Addition
- Subtraction
- Multiplication
- Division

The `Divide` method includes validation to handle division by zero. If the divisor is zero, a warning message is displayed.
## Features

- Perform addition of two integers
- Perform subtraction of two integers
- Perform multiplication of two integers
- Perform division of two integers
- Handle division-by-zero scenarios safely
- Simple and reusable utility class

## Operations Available

- `Add(int number1, int number2)`
- `Subtract(int number1, int number2)`
- `Multiply(int number1, int number2)`
- `Divide(int number1, int number2)`
